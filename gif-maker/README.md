# GIF 메이커

영상을 넣고 A, B, C… 구간을 정한 뒤 **한 번에 GIF로 자르고 만들고 저장**하는 도구입니다.
캡컷/프리미어처럼 뷰어 · 타임라인 · 설정 · 상태 확인 창이 한 화면에 있습니다.
영상은 어디에도 업로드되지 않고 **내 컴퓨터(브라우저) 안에서만** 처리됩니다.

## 실행 방법 (둘 중 편한 것)

### 1) 그냥 열기
`gif-maker` 폴더의 `index.html`을 크롬(또는 엣지)으로 열면 끝. 인터넷 연결 없어도 됩니다.

### 2) 크롬 확장 프로그램으로 설치 (툴바 아이콘으로 바로 열기)
1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → `gif-maker` 폴더 선택
4. 툴바의 GIF 아이콘(퍼즐 모양에서 고정 가능)을 누르면 새 탭으로 열립니다

## 사용 순서

1. **📂 영상 열기** 또는 화면에 영상 끌어다 놓기
2. 구간 만들기 (원하는 만큼 A, B, C, D…)
   - 재생/이동하다가 `I`(시작) → `O`(끝) → `Enter`(구간 추가)
   - 또는 타임라인 **구간 줄(색 블록이 놓이는 줄) 빈 곳을 드래그**해서 바로 그리기 (`Alt`+드래그는 썸네일·눈금 위에서도 됨)
   - 만든 구간은 타임라인에서 끌어서 이동, 양 끝을 끌어서 길이 조절
   - 아래 표에서 시작/끝 시간을 직접 입력해도 됨 (`1:23.50` 또는 `83.5`)
3. 오른쪽 **GIF 설정**: 가로×세로 px(비율 고정), 크롭, fps, 재생 속도, 색상 수, 반복, 출력 방식
4. 오른쪽 **상태 확인**: 선택 구간의 길이·출력 크기·프레임 수·**예상 용량**(한도 대비 게이지).
   표에서도 구간별 예상 용량이 보이고, 한도에 가까우면 노랑, 넘으면 빨강으로 표시됩니다.
5. **⚡ 선택 구간 전부 GIF 만들기** (체크된 구간만, `Ctrl+Enter`)
6. 왼쪽 **결과물**에서 미리보기·실제 용량 확인 후
   - 하나씩 `⬇ 저장`
   - `📁 폴더에 저장`: 폴더 하나 고르면 전부 그 폴더에 저장 (크롬/엣지)
   - `🗜 ZIP`: 한 파일로 묶어서 다운로드
   - 한도를 넘은 GIF는 **한도에 맞춰 줄이기**로 크기를 자동으로 줄여 다시 만들 수 있음

파일 이름은 `영상이름_A.gif`, `영상이름_B.gif` … (이어붙이기는 `영상이름_ABC.gif`)

## 화질 최대로 뽑는 설정
GIF는 형식 자체가 **한 장면에 최대 256색**이라 원본 영상과 똑같을 수는 없어요. 대신 이렇게 하면 원본에 가장 가깝게 나와요.
- 크기: **원본** 또는 블로그 표시 폭(예: 860)
- 색상 수: **256**
- 팔레트: **프레임별 (색 정확)**
- **디더링 켜기**: 피부·하늘·그라데이션에 생기는 색 계단(밴딩)이 사라짐 (대신 용량 2~3배)
- fps는 화질(선명도)과 상관없고 움직임 부드러움·용량에만 영향

## 용량 줄이는 요령
- 가로 크기를 줄이는 게 가장 효과가 큼 (480 → 360이면 대략 절반 가까이)
- fps 10~12면 블로그용으로 충분히 자연스러움
- 색상 수 128/64로 낮추기
- 팔레트 **공통** + **정지 영역 압축** 켜기 (화면 녹화·고정 화면 영상에서 특히 효과 큼)
- 예상 용량은 몇 프레임을 샘플로 인코딩해 계산한 값이라 실제와 약간 다를 수 있음

## 단축키
상단 **⌨ 단축키 설정**에서 동작마다 키를 직접 바꿀 수 있어요 (바꾸기 / ＋추가 / 지우기 / 기본값으로).
설정은 브라우저에 저장되고, 한글 입력 상태에서도 그대로 동작합니다.

| 기본 키 | 동작 |
|---|---|
| `Space` | 재생 / 정지 |
| `←` `→` | 1프레임 이동 (`Shift`: 1초) |
| `I` / `O` | 시작점 / 끝점 표시 |
| `Enter` | 표시한 범위로 구간 추가 |
| `[` / `]` | 선택 구간의 시작 / 끝을 현재 위치로 |
| `Tab` / `Shift+Tab` | 다음 / 이전 구간 선택 |
| `C` | 선택 구간 체크 켜기/끄기 |
| `Delete` | 선택 구간 삭제 |
| `L` | 구간 반복 재생 |
| `Home` / `End` | 구간(또는 영상) 처음 / 끝 |
| `G` | 선택 구간만 GIF 만들기 |
| `Ctrl+Enter` | 체크된 구간 전부 GIF 만들기 |
| `Ctrl+O` | 영상 열기 |

## 참고
- 브라우저에서 재생되는 영상만 열 수 있어요 (mp4 H.264, webm 등). 아이폰 HEVC(.mov)가 안 열리면 mp4로 변환 후 사용하세요.
- 긴 구간·큰 크기는 만드는 데 시간이 걸리고 메모리를 많이 씁니다. 진행 중엔 **취소** 가능.
- GIF 인코더: [gifenc](https://github.com/mattdesl/gifenc) (MIT, `vendor/`에 포함)
